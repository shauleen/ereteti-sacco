ERETETI DAIRY SACCO - LOCAL XAMPP PROJECT

INSTALL:
1. Start Apache in the XAMPP Control Panel.
2. Start MySQL only if your lab requires a database.
3. Extract the ereteti-sacco folder into C:\xampp\htdocs\
4. Open VS Code and choose File > Open Folder > C:\xampp\htdocs\ereteti-sacco
5. Open http://localhost/ereteti-sacco/ in your browser.

IMPORTANT:
- Keep all files and folders in their current arrangement.
- Add your real image file as img/collection-centre.jpg. The project includes the img folder but no supplied image.
- The membership form sends its data by POST to process-register.php. This demonstration validates and displays the data but does not store it in a database.
- The delivery form is a front-end demonstration and does not save records to a database.
- Replace sample contact details, notices, dates and route information if your lecturer has supplied updated information.
- XAMPP is for local development and classroom testing, not public production hosting.
